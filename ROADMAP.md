# Roadmap

MarketPrice focuses on explainable spreadsheet-based pricing for sellers and accountants. The items below are proposals and validation goals, not promises of completed features or dates. See [development flow](DEVELOPMENT_FLOW.md) and [known limitations](KNOWN_LIMITATIONS.md) for current boundaries.

## 1. Make the first review easier

- Observe new users completing the synthetic sample without assistance. Record where mapping, missing costs, currencies or exports cause confusion; improve the highest-impact obstacles.
- Refresh public screenshots or a short walkthrough using synthetic data only. Verify each image for private information before publishing.

## 2. Establish trust with real workflows

- Validate one real seller template and one current fee contract with the owner's permission. Keep the source data private and publish only sanitized examples and independently checked results.
- Run a five-seller pilot and record whether users can reproduce a decision and understand provisional results. Do not claim time saved or financial accuracy without evidence.
- Verify the experimental Excel button on supported desktop versions and document the tested environments.

## 3. Expand only after validation

- Prioritize the most frequent import or fee-rule gaps found in the pilot, with independent financial examples and boundary tests.
- Evaluate authorized, read-only marketplace integrations after validating data requirements, incomplete responses, credentials and privacy. Marketplace writes remain a later decision, not a current feature.

Feedback is welcome through GitHub issues using synthetic examples. Please report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
